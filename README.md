# NEXUS

Decentralized identity and encrypted data ownership platform.

## Architecture

```
nexus-core/     — Core Rust library (crypto, identity, storage, networking)
nexus-tauri/    — Tauri 2.0 desktop + mobile shell
nexus-ui/       — Svelte + TypeScript frontend (planned)
docs/           — Planning documents
```

## Building

```bash
cargo build
cargo test
```
